## What Changed

**File:** `web/src/styles.css` (lines 3322–3343)

The `≤640px` mobile media query now makes the topbar a **2-row layout**:

- **Row 1:** `.topbar__left` (hamburger + brand) and `.topbar__right` (theme switcher + notifications + logout) side by side
- **Row 2:** `.topbar__center` (the "Ask dockyard" search input) spanning full width

This was achieved by adding `flex-wrap: wrap` to `.topbar` and setting `order: 3` / `flex: 0 0 100%` on `.topbar__center` so it wraps to its own row. The pattern matches what already works at the `≤780px` breakpoint.

Before this fix, all three sections competed for space on a single narrow row at phone widths — the search input had almost no room to type.
