## Response

## Summary

### Root Cause

The empty button was at `web/src/pages/ProjectDetail.tsx:294-296` — an edit-toggle button in the left panel header:

```tsx
<button className="btn btn--ghost btn--sm" onClick={() => setEditing(!editing)}>
  <AppIcon name="edit" />
</button>
```

The `AppIcon` component (`web/src/icons.tsx:98`) resolves the icon name against the `UI_ICONS` map. The name `"edit"` **does not exist** in that map — `UI_ICONS['edit']` evaluates to `undefined`. When `FontAwesomeIcon` receives `icon={undefined}`, it renders nothing, producing a literally empty button with zero visible content.

(Even though the TypeScript type is `keyof typeof UI_ICONS`, the build pipeline likely transpiles via Babel without type-checking, so the invalid key slipped through.)

### What I Changed

In `web/src/pages/ProjectDetail.tsx`:

1. **Removed the empty edit button** from the left panel header button row (the `btn--ghost btn--sm` with `<AppIcon name="edit" />`).
2. **Removed the three associated state variables** (`editing`, `editName`, `editDesc`) — they were only toggled/set by the edit button and its form.
3. **Removed the `setEditName`/`setEditDesc` calls** in the `load()` function.
4. **Removed the inline editing form** (name/description inputs + Save button) that was gated behind `editing &&` — now unreachable dead code.
