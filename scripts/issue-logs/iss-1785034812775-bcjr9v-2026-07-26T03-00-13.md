## Root Cause

The "Ask Dockyard" toolbar input uses the CSS class `.assistant-search`, which in `styles.css:209` has a hardcoded `background: #eceef3` — a light gray color. While the dark theme CSS (`themes/dark.css`) overrides many component-specific styles (panels, cards, tables, modals, topbar, etc.), it was **missing an override for `.assistant-search`**. The inner `<input>` has `background: none`, so it inherits the parent's light background.

The same gap existed for `.search-input` (used in the sessions sidebar offcanvas), which also had `background: #eceef3` with no dark theme override.

## Fix

Added dark theme overrides in `/app/web/src/themes/dark.css` for:

- **`.dark-theme .assistant-search`** — replaces the light `#eceef3` background with `var(--bg-elev-2)` (`#18181f`, a dark surface), updates border to `var(--border-strong)`, and adjusts the inset shadow for dark mode. Hover now uses the accent color for the border. Focus-within uses `var(--bg-elev)` for the elevated focus state.
- **`.dark-theme .search-input`** — same treatment for the sidebar search input.

The fix follows the existing dark theme conventions: using `var(--bg-elev-2)` for darker input backgrounds, `var(--border-strong)` for borders, and appropriate dark-mode shadows.
