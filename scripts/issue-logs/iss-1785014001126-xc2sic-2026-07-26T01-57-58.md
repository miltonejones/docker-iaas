## Diagnosis

The issue is in `/app/web/src/icons.tsx:58`. The gateway navigation icon was mapped to `faCircleNodes` — a network/node diagram icon from FontAwesome. The issue requests a "browser icon" for gateways. `faGlobe` is the standard FontAwesome globe/browser icon, and it was already imported (line 24) and used elsewhere (for the nginx preset icon), so it's readily available.

**Root cause:** The gateway icon was mapped to `faCircleNodes` (a generic network icon) instead of `faGlobe` (a browser/globe icon), which better represents a gateway/reverse-proxy service that routes browser traffic.

**Fix:** Changed the `gateway` entry in the `UI_ICONS` record from `faCircleNodes` to `faGlobe`.
